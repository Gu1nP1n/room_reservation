# ThisIsMyRoom - API сервис бронирование переговорок

## Описание проекта

ThisIsMyRoom - cервис для бронирования переговорных комнат с разграничением прав доступа. Позволяет пользователям резервировать время использования переговорных комнат, управлять своими бронированиями и просматривать расписание занятости помещений.

## Основной функционал

- **Регистрация и аутентификация пользователей** с использованием JWT-токенов
- **Управление переговорными комнатами** (создание, редактирование, удаление)
- **Бронирование переговорных комнат** с указанием времени начала и окончания
- **Просмотр списка всех бронирований** для конкретной комнаты
- **Управление своими бронированиями** (редактирование, удаление)
- **Проверка пересечений бронирований** для исключения конфликтов
- **Разграничение прав доступа** между обычными пользователями и администраторами

## Используемые технологии

- **Python 3.10+**
- **FastAPI** — веб-фреймворк для создания API
- **SQLAlchemy** — ORM для работы с базой данных
- **Alembic** — инструмент для миграций базы данных
- **FastAPI Users** — библиотека для управления пользователями и аутентификации
- **Pydantic** — валидация данных и настройки приложения
- **SQLite** (через aiosqlite) — база данных
- **Uvicorn** — ASGI-сервер для запуска приложения

## Структура .env файла

Создайте файл `.env` в корневой директории проекта со следующим содержимым:

```env
# Название приложения
APP_TITLE=Бронирование переговорок

# Описание приложения
DESCRIPTION=Сервис бронирования переговорных комнат

# Строка подключения к базе данных
DATABASE_URL=sqlite+aiosqlite:///./room_reservation.db

# Секретный ключ для JWT-токенов (сгенерируйте свой!)
SECRET=secret

# Данные первого суперпользователя (опционально)
FIRST_SUPERUSER_EMAIL=admin@example.com
FIRST_SUPERUSER_PASSWORD=adminpass
```

> **Важно:** Измените значение `SECRET` на собственное секретное значение!

## Инструкция по запуску проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/Gu1nP1n/room_reservation.git
cd room_reservation
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/MacOS:**
```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта (см. раздел "Структура .env файла").

### 6. Применение миграций

```bash
alembic upgrade head
```

### 7. Запуск приложения

```bash
uvicorn app.main:app --reload
```

Приложение будет доступно по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## Права доступа и возможности пользователей

### Анонимный пользователь (неавторизованный)

**Возможности:**
- Регистрация нового аккаунта
- Авторизация в системе

**Ограничения:**
- Не может просматривать переговорные комнаты
- Не может создавать бронирования
- Не имеет доступа к функционалу системы

### Авторизованный пользователь

**Возможности:**
- Просмотр списка всех переговорных комнат
- Создание бронирований переговорных комнат
- Просмотр своих бронирований
- Редактирование своих бронирований
- Удаление своих бронирований
- Просмотр расписания занятости конкретной переговорки

**Ограничения:**
- Не может создавать/редактировать/удалять переговорные комнаты
- Не может редактировать/удалять чужие бронирования
- Не может просматривать список всех бронирований в системе
- Не может удалять других пользователей

### Суперпользователь (администратор)

**Возможности:**
- Все возможности авторизованного пользователя
- Создание новых переговорных комнат
- Редактирование переговорных комнат
- Удаление переговорных комнат
- Просмотр всех бронирований в системе
- Редактирование любых бронирований
- Удаление любых бронирований
- Управление пользователями (просмотр, редактирование)

**Ограничения:**
- Нет возможности удалять пользователей через API (функция отключена)
